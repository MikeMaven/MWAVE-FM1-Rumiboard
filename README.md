# Rumiboard

Custom firmware for the M-VAVE FM-1: a lofi-focused synth, sampler and groovebox.

Rumiboard is a fork of [Melodee](https://github.com/keremimo/melodee) (Kerem Kilic, Ellic Studio),
which is itself derived from [Felucca](https://github.com/hugelton/Felucca) (Leo Kuroshita,
Hügelton Instruments). It is free software under **GPL-3.0-only**; see [LICENSE](LICENSE),
[LICENSING.md](LICENSING.md) and the original notices kept in each source file.

- [docs/VISION.md](docs/VISION.md): sound design brief, hardware constraints and plan
- [docs/UI_DIRECTION.md](docs/UI_DIRECTION.md): look and feel
- [docs/MELODEE_README.md](docs/MELODEE_README.md): the upstream Melodee README (install, recovery,
  features of the base firmware)
- [BUILDING.md](BUILDING.md): building from source
